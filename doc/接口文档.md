# 用户中心 API 接口文档

## 基础信息

- **Base URL**: `http://localhost:8080/api`
- **Content-Type**: `application/json`
- **响应格式**: 统一使用 `BaseResponse<T>` 封装

## 响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "description": ""
}
```

## 接口列表

### 1. 用户注册

**接口地址**: `POST /api/user/register`

**请求参数**:
```json
{
  "userAccount": "zhangsan",
  "userPassword": "123456",
  "checkPassword": "123456",
  "planetCode": "10001"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userAccount | String | 是 | 用户账号 |
| userPassword | String | 是 | 用户密码 |
| checkPassword | String | 是 | 确认密码 |
| planetCode | String | 是 | 星球编号 |

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": 1,
  "description": ""
}
```

---

### 2. 用户登录

**接口地址**: `POST /api/user/login`

**请求参数**:
```json
{
  "userAccount": "zhangsan",
  "userPassword": "123456"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userAccount | String | 是 | 用户账号 |
| userPassword | String | 是 | 用户密码 |

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "username": "张三",
    "userAccount": "zhangsan",
    "avatarUrl": "https://example.com/avatar.jpg",
    "gender": 1,
    "phone": "13800138000",
    "email": "zhangsan@example.com",
    "userStatus": 0,
    "userRole": 0,
    "planetCode": "10001",
    "createTime": "2026-06-12T10:00:00",
    "updateTime": "2026-06-12T10:00:00"
  },
  "description": ""
}
```

**说明**: 
- 登录成功后会将用户信息存储到 Session 中
- 返回的用户信息已脱敏（不包含密码等敏感字段）

---

### 3. 用户注销

**接口地址**: `POST /api/user/logout`

**请求参数**: 无

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": 1,
  "description": ""
}
```

**说明**: 清除 Session 中的用户信息

---

### 4. 搜索用户（需要管理员权限）

**接口地址**: `GET /api/user/search?username=张`

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名（模糊搜索） |

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 1,
      "username": "张三",
      "userAccount": "zhangsan",
      "avatarUrl": "https://example.com/avatar.jpg",
      "gender": 1,
      "phone": "13800138000",
      "email": "zhangsan@example.com",
      "userStatus": 0,
      "userRole": 0,
      "planetCode": "10001",
      "createTime": "2026-06-12T10:00:00",
      "updateTime": "2026-06-12T10:00:00"
    }
  ],
  "description": ""
}
```

**权限要求**: 仅管理员（userRole = 1）可访问

---

### 5. 删除用户（需要管理员权限）

**接口地址**: `DELETE /api/user/{id}`

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 用户 ID |

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": true,
  "description": ""
}
```

**权限要求**: 仅管理员（userRole = 1）可访问

**说明**: 采用逻辑删除，不会真正从数据库中删除记录

---

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 无权限 |
| 500 | 服务器内部错误 |
